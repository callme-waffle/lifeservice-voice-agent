## 구성 요소

## 에이전트 작업 규칙

이 저장소는 에이전트 지향 프로젝트 하네스로 구성되어 있습니다. 모든 코딩 에이전트는 작업 전 [AGENTS.md](AGENTS.md)를 반드시 읽어야 합니다.

- 작업 기록: `docs/records/` (이슈 → 계획 → 로그 / 결정)
- 워크플로우: `.agents/workflows/`
- 문서 템플릿: `.agents/templates/`
- 세션 상태: `.agents/sessions/`
- 요구사항 문서(PRD/SRS): `docs/ideas/`
- 이슈 ID 접두어: `VOIC` (예: `VOIC-FEAT-001`)
