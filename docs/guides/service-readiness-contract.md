M9의 수용 수치와 ADR-013 B안 설계는 사용자 병합으로 인수됐다. 이는 측정 성능·SLA·M11 구현·운영 개시 승인과 다르다. 미정인 현장 입력은 병합으로 채워지지 않는다. M10 실행안은 [승인 계획 부록 A](../records/1_plans/VOIC-OPS-008-plan.md#부록-a-m10-gate-2-실행안)를 따른다.

## 1. 제공 범위와 역할

첫 개시는 전체 FXO 착신, 정확한 허용 번호 발신, 같은 통화의 연속 한국어 대화·상대 종료, 착신 목록과 발착신 대화 조회다. 웹·전화를 합쳐 활성 세션 1개, PSTN 회선 1개이며 Caller ID는 표시 정보다. 백엔드 중지 중 부재중 전화 기록, 발신 목록, 녹음 다운로드, 웹 사용자 화면, FXS 독립 발신, 외부 업무 도구 실행은 첫 개시 제공 기능이 아니다. PRD-01/04는 후속 요구로 유지한다.

## 3. 시험·운영 승인 경계

- **Gate 1 승인:** OPS-008 전화/조회·품질·복구·제한 운영 묶음의 필요성은 2026-10-16 승인됐다.
- **Gate 2 미승인:** 담당 독립 채팅이 명령, 후보 SHA/이미지, 장비·파일·키 경계, 대상 참조명, 통화 수, 시간, 회선 영향, 중지·원복을 구체화한 실행안 MR을 작성한다. 통합시험 생성·실행 직전 담당 채팅에서 명시 응답으로 해당 묶음을 승인받는다. 2026-10-16 사용자 정정에 따라 준비용 MR 선행 병합은 불필요하며 독립 구현·단위 검증·준비를 계속한다.
- **개별 발신 직전 요청:** Gate 2와 별개로 매번 김화균에게 먼저 요청한다. 승인된 통화 수를 넘거나 실패 후 다시 발신할 때도 새 요청이 필요하다. 무응답이면 발신하지 않는다.
- **M9 경계:** 실전화 0건, 장비 변경·서비스 기동·비밀 전달·재부팅·통합 시험 생성/실행 없음. 이 MR 병합은 내용이 없는 후속 운영 행위를 승인하지 않는다.
- **후속 조건:** 부모가 M9 사용자 병합을 확인했고 2026-10-16 새 M10 독립 채팅이 시작됐다. M10은 준비·실행안 작성이 가능하지만 통합시험은 Gate 2, 실제 환경 기동·전화는 해당 실행 승인과 P0-A→기동→P0-B 조건을 충족한 뒤 수행한다.

M10 실행안은 [M6 잔여 실행서](m6-remaining-test-runbook.md)의 P0→F01→F02/F03→F04/F05와 필요한 D01/D02/D03 의존성을 유지한다. 최초 후보는 F02 발신 1회·F03 착신 1회·F04 착신 2회, F05 조건부 1회를 참조하되 실제 묶음·추가 진단 통화 수는 현장 입력 후 실행안에서 확정한다. 지금 이 문서는 시험 예약 또는 Gate 2 요청이 아니다.

시험 전 FXO Idle·활성 통화 없음·정확 허용 번호 설정·모델 ready·백엔드 상태·설정 백업·같은 키/데이터 참조를 확인한다. 실패하면 신규 발신을 중단하고 인증된 취소/정상 종료로 BYE를 보내 회수한 뒤 현장 FXO Idle을 확인한다. 정리가 안 되면 김화균이 장비 회수 여부를 결정하며 검증되지 않은 FXS 자동 우회를 켜지 않는다. 기존 키나 데이터 볼륨을 지우지 않는다.

## 4. 비밀·백업·복구 검토

[ADR-013](../records/3_decisions/ADR-013-secret-recovery-and-backup.md)의 보호된 호스트 비밀 원본→부팅 시 tmpfs 주입, 별도 암호화 백업 B안은 M9 MR 병합으로 **설계 인수**됐다. 구현·운영 배포는 M11 범위이며 아직 수행되지 않았다. 기존 보존 키 유지, 권한 실패 시 시작 차단, 오프라인 복구 사본과 암호문 백업의 30일 만료, 잘못된 키 확인 방법, 자동 복구와 수동 복구의 차이를 ADR에 명시했다.

## 5. MR 리뷰와 이후 확정할 입력

M9 MR에서 기준 SHA·전화 우선 범위·정량 목표·ADR-013 B안 설계를 인수했다. 담당자와 발신 직전 요청은 이미 확정됐다. M10 시험은 고정 예약 없이 준비 시 요청하며 참여자 정보는 기록하지 않는다. 이전 채팅과 현재 읽기 조사에서 접속·로컬 비밀 설정·기존 데이터 경로를 확인했다. 운영 시간·장애 채널·상시 백업 매체/복구 권한은 후속 적용 전 미정으로 남긴다. 후속 적용 전 김화균이 확인해야 한다. M9 설계 인수와 별개로 미정 항목을 임의로 채우거나 상시 운영 합격으로 표시하지 않는다.
