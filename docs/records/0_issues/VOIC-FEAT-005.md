# 1. 이슈 내용

## A. 배경

한 통화의 최종 사용자 전사와 AI 응답은 암호화된 턴별 파일로 보존되지만, 통화 ID를 지정해 두 방향의 대화내역을 읽는 인증 API가 없다. 현재 운영 API는 발신 시작·상태·취소만 제공한다.

## B. 이슈 설명

인증된 운영자가 각 통화의 사용자 측 최종 전사와 AI 측 최종 응답을 대화 순서로 조회할 수 있어야 한다. 외부 착신과 AI 발신 모두 같은 통화 ID 기준으로 처리하고, 저장되지 않은 턴·삭제된 통화·손상된 암호문을 임의로 복원한 것처럼 보이면 안 된다. 대화 원문은 일반 로그·URL·오류 메시지에 노출하지 않으며 기존 암호화·30일 보존 정책을 유지한다.

---

# 2. 결정 사항

## A. 결정 내용

이 기능을 통화별 대화내역 조회라는 독립 작업으로 추적한다. 조회 API와 정확한 응답 형식은 별도 계획에서 정한다.

## B. 결정 사유

현재 보존 파일은 서비스 내부 아티팩트이며, 운영자가 통화별 대화 흐름을 안전하게 확인할 계약이 없다.
