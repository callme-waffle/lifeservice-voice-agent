# 1. 이슈 내용

## A. 배경

사용자는 현재 작업을 공개 GitHub 저장소에 게시하고 기능별 PR을 요청했다. 기존 추적 문서·설정·시험에는 실제 내부망 주소와 작업 API 도메인이 포함돼 있었고, 기존 커밋 이력을 그대로 게시하면 최신 파일을 수정해도 이전 값이 공개된다.

## B. 이슈 설명

공개 저장소에는 실제 운영 주소·서비스 도메인·전화번호·비밀이 포함되지 않아야 한다. 문서에는 식별값을 마스킹하고, 실행에 필요한 값은 Git 추적 대상이 아닌 로컬 `.env` 또는 호스트 환경파일에서 제공해야 한다. 공개 브랜치의 이력에도 이전 민감값이 남지 않아야 한다. 기능별 개발 브랜치는 이 정리된 기준 브랜치에서 시작해야 한다.

---

# 2. 결정 사항

## A. 결정 내용

사용자가 공개 저장소 유지와 문서 마스킹·로컬 환경변수 분리를 직접 지시했다. 공개 기준 브랜치는 검증된 현재 파일의 새 루트 커밋으로 만들고 기존 로컬 이력은 별도 로컬 브랜치에 보존한다.

## B. 결정 사유

현재 파일만 마스킹한 뒤 과거 커밋을 함께 업로드하면 이전 값이 계속 조회된다. 배포 파일이 예시 주소를 실제 대상으로 사용하지 않도록 환경변수 주입을 명시해야 한다.
