# 1. 이슈 내용

## A. 배경

VOIC-FEAT-010의 실제 Live 착신 시험에서 사용자는 음성 대화가 잘 동작했고 대화 중 직접 통화를 종료했다고 확인했다. 시험 서버는 5분 제한의 일회용 컨테이너로 실행했다.

## B. 이슈 설명

통화 기록은 2026-11-01 23:17:02 KST started, 23:18:28 failed다. Docker kill 23:18:26 및 프로세스 정상 종료/컨테이너 삭제 23:18:28과 서버 기록 종료 시점이 일치하지만, 이는 사용자 종료 원인이 자동 종료라는 증거가 아니다. 사용자 종료 시각과 SIP BYE 수신 자료가 없어 상대 종료 감지·전달·앱 처리·시간 제한 경합 중 원인은 미확정이다.

입력 약 84.06초, 실제 송신 80.56초 및 전사 파일 232건이 암호화 보존돼 음성 대화와 기록 경로는 확인했다. 정상 상대 종료 처리 및 서버의 ended 기록은 검증하지 못했다. 정상 종료가 전달되지 않으면 회선 점유·모델 세션과 사용량이 남을 수 있으므로 별도 확인해야 한다. 이번 시험 프로세스와 SIP/RTP 포트는 이미 종료됐다.

# 2. 결정 사항

## A. 결정 내용

음성 대화 성공과 정상 종료 검증을 구분한다. 본 건은 사용자 종료와 서버 기록의 불일치 조사 항목이며, HT813 설정 또는 Live 코드가 원인이라고 확정하지 않는다. 장비 설정 변경이나 추가 통화를 자동 실행하지 않았다.

## B. 결정 사유

사용자의 직접 종료 진술은 사실로 반영해야 한다. 서버가 나중에 자동 정리됐다는 사실만으로 정상 사용자 종료 감지가 검증됐다고 볼 수 없다.
