# 1. 이슈 내용

## A. 배경

HT813 FXO를 거친 외부 착신이 AI와 통화하는 흐름은 실장 시험을 거쳤으나, 종료된 착신 통화 목록을 조회할 API가 없다. 기존 암호화 보존은 턴별 녹취·최종 전사·응답을 저장하지만 통화 단위의 시작·종료 상태나 발신자 번호를 조회 가능한 기록으로 제공하지 않는다.

## B. 이슈 설명

인증된 운영자가 외부 사용자의 발신에 따른 AI 착신내역을 통화 단위로 조회할 수 있어야 한다. 목록에는 통화 ID, 시각, 상태 등 통화 메타데이터와 **발신자 번호 전체**를 포함한다. 장비가 번호를 보내지 않았거나 유효한 번호가 없으면 번호가 없음을 구분해야 한다. 전화번호는 일반 로그·파일명·삭제 감사에 노출하지 않고, 기존 보존 기간 및 인증 경계를 따라야 한다. 현재 수신 이력과 과거 기록의 가용성 차이를 명확히 해야 한다.

---

# 2. 결정 사항

## A. 결정 내용

이 기능을 착신내역 조회라는 독립 작업으로 추적한다. 사용자는 처음에는 발신자 번호 없는 목록을 선택했으나, 곧바로 **번호 전체 포함**으로 정정했다. 구체적인 API 경로·저장 형식·페이지 처리 방식은 별도 계획에서 정한다.

## B. 결정 사유

현재 통화 내용 보존만으로는 운영자가 어느 사용자의 착신 통화인지 식별하거나 통화 단위 결과를 조회할 수 없다. 번호 전체 저장·조회는 기존 비식별 기록보다 민감도가 높아 별도 설계와 검증이 필요하다.
